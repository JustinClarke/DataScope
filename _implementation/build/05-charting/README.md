# 05 — Chart Modules

**Tier:** v0 · **Phase:** 3 — **the v0 ship gate** (§19, D15) · **Depends on:**
[`../04-sql/`](../04-sql/) (chart translator + grid) and [`../03-profiling/`](../03-profiling/)
(broker gating, column dropdowns).

The four capability-gated chart modules plus the **Join Graph (beta)** (D24,
[05-join-graph-beta.md](05-join-graph-beta.md)). Phase 3 also delivers the **insight feed
(D10)** — specced with the profile UI in
[`../03-profiling/04-profile-ui.md`](../03-profiling/04-profile-ui.md) since it lives on the
profile dashboard and needs the chart translator built here-adjacent — and the
**structure-report export (D20/D31, §12.2)**: one-click client-side export of the structure
report (schema, types, profile aggregates, insight feed, join graph) with **three renderers
over one artifact**: self-contained HTML (design pass + attribution footer, D26), **DSPS
JSON** (the versioned DataScope Profile Spec — a **first-class, open interface** with an
explicit `dsps_version` and forward/backward-compat + schema-only degradation semantics, D37;
field-level spec in
[`../08-persistence/03-dsps-spec.md`](../08-persistence/03-dsps-spec.md)), and the **"Copy for
AI"** LLM-context block (zero raw rows; ~1 day). Entirely client-side, zero server surface
(D15 intact); this is v0's shareable artifact. Phase 3 additionally ships the **consumer
templates + `/spotify` + `/google-takeout` pages, unmarketed (D30, §14)** and the §24
launch-craft gate items (wifi-demo script + video, three intent landing pages, D25 counters
flowing); the full ship-gate additions table is §19 Phase 3, cut order per D27.

Shared rules for all four modules:
- Enabled/disabled strictly by the broker flag named in each doc; disabled = greyed card
  with a *why* tooltip (§9, §13).
- **Every chart is generated by DuckDB SQL, and the SQL is shown alongside the chart** in
  the educational panel — users learn the query patterns (§10).
- Dropdowns pre-populate from the broker's column-reference arrays.
- Each module accepts an optional **`ThreadConfig` prefill (D68e)** — a Verdict `RankedAction`
  opens it pre-configured (columns pre-selected, chart pre-run), not empty.
- Recharts for declarative charts; D3 canvas mode for 10k+ point scatters (§15).
- v0 ship also pulls forward Phase-6 polish: loading/error/empty states per module (D15).
